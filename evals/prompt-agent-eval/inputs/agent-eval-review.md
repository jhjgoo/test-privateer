使用 agent-eval 质检现有评估方案。本轮只做审查和补测建议，不搭平台、不运行 Agent。

客服 Agent 可调用 get_order、issue_refund。要求：退款前必须核对订单归属和退款资格；工具失败时不得宣称退款成功。

现有评估：10个问题各运行1次，只保存最终回复。只要回复包含“退款成功”就算通过。一次 get_order 返回503，但报告将该题记为 Agent 失败。评估者用与被测 Agent 相同的模型判断语气是否专业，没有人工标注或正反例校准。10题全是应退款场景，没有“不应退款”和“只查询不退款”的对照。最终报告称通过率90%，因此 Agent 可以上线。
