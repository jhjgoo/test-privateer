本目录保存输入和判据，不把计划、静态检查或模型自述当作效果证据。原始运行放 `.local/validation/test-communication/`；本 README 不表示当前版本已经验收。

## 当前协议

当前 change 改为先完成候选，再做 A/B 和人工评测；旧轮次不再作为实施门槛。A 为固定基线，B 为本轮实际候选文件，不追加表达提示。两版在隔离会话读取各自真实文件，保存配置、文件哈希、完整输出及加载记录；漏读如实记录，不用注入代替。

首轮七组各做一次 A/B，共 14 份输出：`../report-language/input.md`、`../history-regression/inputs/unclear.md`、`inputs/branch-analysis.md`、`inputs/task-plan.md`、`../test-surface-language/input.md` 的混合请求、`inputs/single-case.md`、`inputs/short-answer.md`。沿用下方事实判据，比较重点与理解、行动与用途、准确与边界；选 2～3 组完整结果供用户评阅。只按实际问题补受影响回归，不机械重复全套。

运行前按实际环境记录命令与版本，不新增运行器。七组 A/B 与后续定向复测已经完成；用户认可 B7 报告和 B12 新版分析的清晰度，B12 同一终稿通过章节、重点、短句及内容完整性的联合审阅。仍保留 B11 标题回退、少量长句及未稳定遵循的限制，不据有限样本声称全包或跨宿主稳定。收尾修订稿与原始输出分开，文档修正不计入生成效果证据。下述命令和旧 B／F 标签仅用于复查历史，不是本轮结果。

## 固定输入与判据

| 输入／用途 | 来源事实与必须保持的读者能力 |
| --- | --- |
| report：复用 ../report-language/input.md | 沿用该套件全部判据；区分 build-21/24，C-016 正确拒绝，C-017 规则未知／布尔缺字段／空列表未测；不填补 C-018、R-005～R-008 的定义，不伪造全量覆盖或亲自执行；读者能找到下轮准备与判法 |
| unclear：复用 ../history-regression/inputs/unclear.md | 在完整模型前确认排队任务的账号取值时点，推荐与理由仍是待确认，不给实施准入；读者知道要回答什么及答案如何改变测试 |
| task-plan | reminder-8 沙箱、QA／值班开发、版本与账号准备、三条给定命令、batchId 依赖、两次尝试与一条最终提醒、失败保留／仅成功后清理、清理失败是环境遗留；可据此接手，不把互斥结果变顺序；不执行、不编就绪 |
| branch-analysis | 有效证／库存、唯一未结束预约、两类取消库存差异、顺序与失效跳过、>48 小时与恰好边界、冻结例外和恢复顺序；全部测试点有安排，优先项明确；不自动写具体用例或上线判断；只有帮助解释关系时才需要图 |
| short-answer | 原句准确，保留范围与未亲自执行，不增虚构缺口、计划或报告 |
| single-case | DOC-9／T-041、三个公开准备观察入口、Token／部署缺口、HTTP 403 与 CARD_EXPIRED、不生成预约；用例独立，无无法操作的内部赋值；不将草案说成可执行或通过 |
| surface 三请求 | 复用 ../test-surface-language/input.md 与 README；分别请求功能用例、单元测试、两者。单元源码／命令未知仍保留缺口，不能编造已运行 RED |
| green／clear | 复用 ../report-language/green.md 与 ../history-regression/inputs/clear.md，保持原套件判据，不虚构未决或重复澄清 |

短答复、单条用例、任务计划都不能按“图少／字少”判优。每个适用读者问题判为直接找到／需自行推断／缺失或错误，并引输出位置。错误规则、遗漏执行依赖、层级混淆、编号或授权变化属于实质错误，不能被阅读收益抵消。版式差异无实际影响时记为保持。

长报告还需检查主要章节与业务子主题能否通过语义标题扫描、定位；加粗行不等于章节标题。按实际内容核对层级，不设固定章节名或数量；短答复不因该规则增加空章节。人工指出 B3 报告全用加粗行；B4 加载共享规则后仍失败，故 B5 在报告交付约定明确层级与对话适用性。两轮均只补 report、short-answer 各一次，失败记录不覆盖，不宣称重复稳定率。

句子表达检查：读者能否直接辨认谁做什么、何时继续或停止，而不必自行拆解多个操作。允许拆句、列表和重复必要主体；条件、例外与精确信息不能丢失。英文 20 词只作写作参考，不设中文硬性字数，不按总字数减少判优。B6 复用 B5 报告与 B3 计划作历史对照，补 report、task-plan、short-answer 各一次；报告仍串联操作，B7 明确分行后仅再测 report 一次。这不是同期 A/B，也不是独立留出测试。
