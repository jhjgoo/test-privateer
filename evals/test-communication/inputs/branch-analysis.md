图书馆预约取书规则：仅有效借阅证可预约，失效证不生成预约。可借库存大于 0 时预约进入待领取并占用一册；无库存则进入排队，不占用库存。同一读者对同一本书只能有一笔未结束预约；已完成或已取消不阻止新预约。读者可取消排队或待领取预约，取消待领取时释放占用，取消排队不增加库存。

归还或取消释放库存后，按排队时间先后分配，同一时刻按预约编号升序；轮到失效证读者时取消其排队项、跳过并尝试下一位，不把库存给失效读者。待领取超过 48 小时未领取自动取消并释放库存；恰好 48 小时仍可领取。管理员冻结某本书时不接新预约，但已进入待领取的读者仍可领取；已排队者暂停分配，解冻后继续保持原次序。

本次最先关注冻结与库存释放同时发生时不能给排队者分配，以及取消待领取后不会多释放库存；卡证、排队顺序和超时边界同样要有明确测试安排，不能丢掉。只有这些业务规则，没有实现、运行环境或现存缺陷证据。
