# 报告与测试语言行为评测

本评测先固定评分标准，再保存无 Skill、旧版和候选版的实际输出。输入为从用户附件问题抽取的合成材料，不包含原附件的个人信息或业务票号。

原始输出、元数据和人工判读保存在本目录被忽略的 `runs/` 或 `.local/validation/`，不随可复用判据提交。本文件不代表当前版本已完成或通过评测。

## 评分标准（运行前固定）

人工阅读实际交付内容，不能按出现了某个标题或关键词计分。

| 项目 | 达标行为 |
| --- | --- |
| 报告重点 | 进入细节前即可找到当前结论、会改变结论的未决项和覆盖限制；知道下一步先补什么。 |
| 结果主体 | C-016 的正确风险拦截属于测试符合预期；C-017 空值语义待确认，不能直接判产品缺陷或通过；布尔样本缺失和空列表未测保持未完成。 |
| 结论边界 | 不支持全量 JSON 覆盖，不照抄全部通过；区分资料记载与亲自验证。 |
| 业务语言 | 摘要和检查目标以业务对象、动作、结果表达；操作与判定中保留识别数据、消除同名字段歧义所需的 JSON 路径、原始值和结构，内部实现名不能替代业务目标。 |
| 语义保真 | 不擅自把枚举翻译成未确认的页面值，不把 null、缺失、空字符串、false、空列表合并；外部 R-001～R-004 原样保留。 |
| 可执行信息 | 下轮检查保留对象、数据/准备缺口、操作、观察和判定依据/规则缺口；没有环境时不冒称可执行。 |
| 追溯 | 发现 C-017/C-018 关联不符、未定义 R-005～R-008；不靠补造一条 Case 或重编号消除问题。 |
| 阅读负担 | 摘要与明细分层，共用准备和长规则不反复横向复制；允许紧凑表或按编号展开，无固定列数与字数评分。 |

邻近设计：API 的路径、认证、精确请求值、状态码和错误码，以及单元层符号、类型、异常、断言和命令均保留；正确的 REJECTED 不是测试失败；如实标记未执行/未取得 RED；不因报告规则强加虚构的运行结论。

合成材料中的 C-016 额外给出了有效拦截规则，用于区分业务结果和测试结果；不代表原附件同号用例已有这条规则，也不是原附件缺陷的复现证据。

## 运行

运行器将所需完整 Skill/模板以固定次序注入单次 CLI 新上下文。control 无 Skill；baseline 从指定 Git 提交读取；candidate 从工作区读取。保存实际 Prompt、哈希、CLI 事件、输出与配置；输出由人工判读。缺少完成事件或出现工具调用时先核对原始轨迹与原因：宿主／环境受阻单列，模型主动违反禁用工具约定属于行为失败，不能自动排除为环境问题。本次说明修订不重判历史结果。

判读时以原始事件为准：传输回退不等于工具调用；隔离要求与完成事件都满足后才进入内容评分。保留原始元数据，不靠回填结果消除运行问题。

```sh
python3 evals/report-language/run.py baseline --ref b17cce447ad8d262c66eb3d5cad3b802b53b3714 --reps 5
python3 evals/report-language/run.py control --reps 5
python3 evals/report-language/run.py candidate --reps 5
python3 evals/report-language/run.py candidate --run-name candidate-v2 --reps 5
```

每组另运行 1 次邻近设计。5 次只能说明该固定任务的重复表现；不等同于跨任务、跨模型的统计稳定性证明。CLI 与桌面自动触发链不同，不能证明所有宿主已生效。

正向边界 `green.md`：另用退款场景检查“本轮全部通过”仍可在有效预期及记录支持下成立，正确拒绝不被误判失败，不因新增报告规则而虚构未决问题、补测或发布决定。仅用于单次迁移检查，不并入五次主任务评分。命令：`python3 evals/report-language/run.py candidate --run-name candidate-green --probe green --reps 1`。

导出兼容性：`export-compact.md` 是源格式，`export-normalized.md` 是按原 ID 合并共用准备与详情的人工核对样本。用现有导出脚本转换后核对两条主题及全部步骤、预期和准备缺口；这验证转换通路，不代表模型已自动完成导出过程。
