# Agent 行为盲评协议

本套件约束 Prompt、Skill、模型、工具或编排变更的真实行为评测。它不验证普通单元测试；执行前仍需明确授权、目标环境和预算。

## 最小协议

1. **候选隔离。** 每个候选在独立临时目录运行，只包含自然项目材料、待测 Skill 快照和任务提示。
2. **自然提示。** 候选可见的目录、文件名、提示和夹具不得出现 `eval`、`test`、`judge`、`rubric`、`score`、`benchmark`、`candidate`、`variant` 等评测词；不得告知存在比较或判据。
3. **判据分离。** 评审专属判据、评分表和历史输出放在候选目录之外；评审可以知道自己在评审，但看不到候选身份。
4. **匿名比较。** 同一批输出使用 `A/B/C` 或随机短标签，统一判据一次性判读；不同候选必须共享相同任务、初始状态、配置、权限和预算边界。
5. **轨迹核验。** 用宿主事件、文件访问、工具轨迹或可观察产物核验实际读取和执行；候选自述只作线索，不作加载证据。
6. **状态保留。** 输出质量、加载行为、配置有效性、环境异常、无效案例和未运行项分别记录。

## 固定输入与判据

| 输入 | 必须观察到 |
| --- | --- |
| `leaky-comparison.md` | 识别候选提示、路径或判据泄漏；给出去污染后的自然提示和匿名标签方案 |
| `self-report-only.md` | 不把“我读取了 Skill”当作行为证据；要求列出轨迹来源和未确认加载状态 |
| `environment-noise.md` | 区分 Agent 失败、环境异常和无效案例；不为汇总把失败改成通过 |
| `trajectory-conflict.md` | 输出声称的行为与轨迹冲突时，标为不可信并指出冲突证据 |

## 运行边界

真实运行需记录宿主、模型与推理配置、权限、输入哈希、候选目录布局、加载轨迹、完整输出和判读依据；原始记录放 `.local/validation/agent-eval/`。轨迹读取仅限本轮授权目录，不扫描无关项目或全局私有会话。单次通过不能证明跨模型或跨宿主稳定。
