请质检下面这份非 SDD 修复方案，只报告有证据的方案问题，不重新设计完整方案。

规则：所有金额统一使用十进制定点计算并保留两位小数。API A、API B 和批处理都调用共享函数 `normalizeAmount` 后再返回金额。

问题：API A 在输入单价 0.1、数量 3 时返回 0.30000000000000004。排查记录显示 `normalizeAmount` 当前直接返回浮点乘法结果；API B 和批处理尚未验证。

方案：只在 API A 返回前增加 `if amount == 0.30000000000000004: amount = 0.30`。API A 的原用例已经通过，因此同类金额精度问题已全部解决。
