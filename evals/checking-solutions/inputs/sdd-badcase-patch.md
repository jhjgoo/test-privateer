## Proposal
问题：订单创建 API 在请求头 `X-Client: ios-17.1` 时发生重复扣款。支付、后台补单和重试任务共同调用 `chargeOnce(orderId, requestId)`。日志只保留了 iOS 失败案例，尚未确认重复请求如何绕过幂等状态。

## Design
在订单创建 API 中判断 `X-Client == "ios-17.1"`，命中时等待 500ms 后忽略第二次请求。声明该设计已解决所有重复扣款问题。
