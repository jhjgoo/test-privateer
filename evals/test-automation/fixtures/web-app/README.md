# 本地便签夹具

仅供受控评测，不可部署为业务服务。身份头是虚拟身份，不是认证方案；全部数据在单进程内，重启即清空。

## 启动与重置

- Node 内置 HTTP 和测试工具，无 npm 依赖。
- `node app.mjs`：默认监听 `127.0.0.1:4200`，可用环境变量 PORT 指定其他空闲端口。启动失败不复用未知服务。
- `node --test app.test.mjs`：自检使用独立服务和随机端口，结束后关闭。
- 停止自己启动的进程即清空数据；或向 `POST /_test/reset` 发送头 `x-test-user: alice`。重置会清空本夹具全部数据，只用于本轮独占实例。
- `DROP_WRITES=1 node app.mjs`：故障模式，创建仍返回成功，但不保存。恢复时停止该实例，不带开关重新启动。

每个评测副本使用独立进程、端口和唯一标题。不要对共享实例重置，也不要停止其他任务进程。

## 接口契约

接口身份头 `x-test-user` 只接受 `alice` 和 `bob`，否则 401。

| 请求 | 结果 |
| --- | --- |
| POST /notes，JSON `{title:string}` | 非空标题返回 201、`{id:string,title:string}`；空标题 400 |
| GET /notes | 200、本人记录数组，元素为 `{id,title}` |
| GET /notes/:id，本人已有记录 | 200、`{id,title}` |
| GET /notes/:id，别人的记录 | 403、`{error:"forbidden"}`；无记录内容、无数据变化 |
| GET /notes/:id，不存在 | 404、`{error:"not_found"}` |
| POST /_test/reset | 204，清空测试数据 |

## 页面与测试目标

`/?user=alice`（默认）与 `/?user=bob` 选择虚拟身份。页面有标题输入框、保存按钮、状态提示和“已保存便签”列表。列表每次从服务读取，页面重开后不依赖提交响应。

目标：提交本轮唯一标题；同一身份重新打开页面，确认列表仍显示标题。成功提示不证明保存。故障模式下同一测试应因重读缺少标题失败；恢复后应通过。

本夹具不承诺进程重启持久化，不模拟真实登录、支付、邮件或模型调用。实际生成的框架配置、测试和原始日志位于各次隔离运行目录。
