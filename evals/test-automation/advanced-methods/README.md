# 进阶验证方法最小行为评测

验证 `designing-test-automation` 是否按风险选择性质／形式方法，并保留真实映射、可失败验证和覆盖边界。判据不提供给候选；原始运行记录放 `.local/validation/test-automation/`。

| 输入 | 必须观察到 |
| --- | --- |
| `concurrency-model.md` | 选择模型检查或可复现并发探针；记录模型假设、边界、工具版本和失败复现方式 |
| `unsupported-model.md` | 未确认规则或真实代码映射时不引入形式化方法；补规则缺口或选择确定性检查 |

两个输入都必须保留“通过只覆盖模型和边界，不证明整个系统”的结论边界。
