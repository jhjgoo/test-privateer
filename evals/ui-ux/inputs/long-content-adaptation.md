# 导航与长内容

独立材料评审。同一版本的附件 fixtures/navigation-wide.png 和 fixtures/navigation-narrow.png 为合成静态画面，模拟同一导航信息在两种状态的呈现。A：960 CSS px 宽，短英文导航“Reports”，主操作“Create”。B：360 CSS px 宽，长译文“Detailed expense reports and settlement history”，主操作仍为“Create”。B 中导航文本占据主操作区域，完整标签不可辨。没有点击命中记录。

用户任务：从报告页创建一条报告。设计约定：窄屏允许导航折行或收起，但主操作标签可辨、入口可达。请根据两张图给出具体问题、最小补证和下一组有价值的适配检查。不要泛列兼容性清单或运行测试。
