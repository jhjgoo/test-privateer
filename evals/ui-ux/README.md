# UI/UX 专项方法行为评测

本目录保存独立合成场景与判据。评测对象是 Skill 的方法选择、分析与证据判断，不是这些虚构产品的真实质量。本文件不传入受测会话。

## 固定判据

| ID | 输入 | 通过条件 | 关键误判 |
| --- | --- | --- | --- |
| E01 | screenshot-boundary | 读取实际图像，完成可见部分分析；动态焦点与恢复保持未知，提出具体补证 | 从截图证明键盘/恢复可靠；或停止全部分析 |
| E02 | approved-visual-change | 依据 D-17 认定预期变化，区分基线更新与未测体验 | 差异即缺陷；整页均合格 |
| E03 | first-use-discovery | 沿首次任务检查目标、动作发现、含义关联和反馈；说明线索、知识假设与验证 | 只报审美问题或泛称难用；编失败率 |
| E04 | zero-alert-focus-loss | 以组件约定及操作轨迹判断焦点返回问题；限定浏览器/状态范围 | 扫描覆盖动态/全部标准；忽略已有观察 |
| E05 | long-content-adaptation | 读取配对图像，指出长内容×窄屏下标签被遮挡，并保留可达性的证据缺口 | 泛列兼容性；仅截图就宣称点击失败 |
| E06 | agent-success-user-difficulty | P1 独立成功，P2/P3 提示后完成，P4 未完成；区分 Agent 与用户 | 将四人算独立成功；自动完成即易用 |
| E07 | unrelated-api-case | 按协议分区，关注边界/类型，保持接口范围 | 因页面一词扩成 UI 专项 |
| E08 | no-product-access | 星形无说明和错误提示违反所给设计；输入保留为未知；直接完成材料评审 | 等安装或环境才分析；把缺标注当实测清空 |
| E09 | equivalent-evidence-tools | 两报告支持同一发现，不增加独立样本；方法不依赖来源品牌 | 两报告当两次独立复现；强制特定工具 |
| E10 | lab-score-field-delay | 区分首页加载分数与搜索等待；缺反馈有约定依据，根因未知，补测具区分力 | 98 分证明 UX；直接断定前/后端根因 |
| E11 | native-ui-context | 使用任务走查，核对平台语义和知识假设，标准适用性保持明确 | 套 DOM/ARIA 或无来源 Web 阈值 |
| E12 | continue-authorized-review | 保留 T-003/C-006/R-002，区分 v3/v4，更新已测姓名保留和提示，重试/其他字段待测 | 重建地图、重复澄清、自行修复；单项通过关闭风险 |

所有输入都以实际语义评分，不能凭出现方法名或标题判通过。PASS 为满足本行全部契约；FAIL 记录原文、影响及依据；BLOCKED 表示环境未取得有效输出，单列。关键失败不被总分平均。

## 对照方式

1. 修改运行时文件前冻结 baseline/skills；候选定稿后冻结 candidate/skills。记录内容哈希、源码提交、工作区差异。
2. 每个场景/重复使用新目录与新会话，仅放技能快照、该 task.md、必要 fixtures；不传本 README、历史答案、评分或研究报告。
3. 两版均先显式读取本地 test-privateer，由它选择下游；候选直接加载和宿主隐式触发另测，不用“基线缺文件”伪造改进。
4. 固定模型、宿主、推理配置、可用工具和权限；记录用户配置及全局规则是否可见。仅提示隔离不等于物理隔离。
5. E01/E02/E04/E06 两版各两次，其余先各一次。图片以真实图像输入提供；只读文本不能计作视觉通过。
6. 保存完整回复、工具轨迹、用量、退出状态、耗时与 stderr；逐条读完整输出，正常能力也作为保护目标。
7. 正常对照涵盖意外视觉变化、熟练用户术语、正确焦点返回。候选定稿后增加长内容与等价报告的保留变体，检验迁移；失败修正不得把保留变体变成唯一示例。

原始运行目录可放临时目录，结论、逐例判定与位置及哈希持久化到被忽略的 `evals/ui-ux/runs/` 或 `.local/validation/`。临时调度脚本不进入 Skill 包或成为使用依赖；可复用运行器按源码维护。每轮明确目标模型与宿主配置，运行时 Skill 不绑定模型。

复跑时向新会话交付以下相同请求，并使用该宿主提供的图像附件能力传入 E01/E05 图片：

> 读取当前目录 skills/test-privateer/SKILL.md 及当前任务需要的下游文件，然后处理 task.md。仅使用当前目录的技能快照和任务材料；不读取其他目录、历史会话、评审答案或网络。只读文件，不执行产品测试，不修改文件；在最终回复交付当前请求的完整结果。

真实产品、长会话和其他模型/宿主效果需各自验证，不从这些合成场景外推。

## 正常对照与保留变体

| 输入 | 判据 |
| --- | --- |
| normal-approved-change-absent | 有效规范未批准改色，明确指出偏离约定；不由此断言对比度或操作失败 |
| normal-expert-terminology | 按已声明专家人群接受 BX 约定，承认已有正向证据；不制造新手术语缺陷，不外推其他人群 |
| normal-focus-return | 所给路径符合返回焦点约定；不报焦点丢失，不扩大为整体合规 |
| heldout-expanded-content | 实际看图发现长文本覆盖 Open；相同空间与主题下准确比较，点击结果仍未知；下一检查有区分力 |
| heldout-reports-independence | A/B 同源、C 为另一次采集；两次原始采集的观察支持发现，三份报告不算三次独立复现；来源名不改变实质判断 |

前三项在两版各运行一次；后两项于候选冻结后编写，未进入运行时示例，两版各运行一次。另以 E03 在候选直接加载一次，并通过临时 `.agents/skills` 暴露候选目录，单独检查不点名入口时的宿主发现与加载轨迹。

E05 的文字输入已提供遮挡观察，因此它验证材料分析和边界判断，不能单独证明视觉发现能力。实际图像观察另看未提供观察答案的 heldout-expanded-content；E01 检查默认图像及动态证据边界。
