# 合成界面夹具

这些 PNG 为固定二维示意图，不是产品截图；用来评估图像证据边界和布局观察。profile-form 只有静态默认表单；navigation 两图改变视口和文本长度，窄图文字覆盖按钮。它们不包含操作、焦点或 DOM 证据。图中文字用英文是为跨运行机器固定字体呈现，长文本模拟译文扩张，不验证真实翻译。校验值见 SHA256SUMS。

## 保留变体

`heldout-compact.png` 与 `heldout-expanded.png` 在候选技能冻结后生成，均为 480px、深色主题，仅导航文字长度不同；用于未提示观察答案的图像比较。仍为合成夹具，无真实产品交互证据。
