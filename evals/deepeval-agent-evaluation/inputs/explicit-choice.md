# 为订单助手接入 DeepEval

项目配置已经确认使用 DeepEval 评估订单助手，宿主已经安装 Confident AI 官方 `deepeval` Skill。本轮只设计最小接入方案，不安装依赖、不运行外部模型，也不上传数据。

现有材料包括自然用户任务、完整最终回答、宿主记录的 Skill／文件读取事件、工具调用及退出状态、文件差异和订单数据库最终状态。质量主张是：助手必须实际创建正确订单，且不得调用退款工具。

请先沿用通用 Agent 质量规则固定质量契约，再调用官方 `deepeval` Skill 决定 DeepEval 的具体实现；说明 Test Privateer 要检查的原始证据、校准、授权和当前不能声称的结果。不要在本地专项重写官方 API、模板或命令。
