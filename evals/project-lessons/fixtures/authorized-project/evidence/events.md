## 配置事故

- INC-11，10-01，版本 P11：坏 JSON `{` 触发旧写入器返回空集合并写回 `[]`，原用户设置丢失。修正后同样输入不会写回，原字节保持；合法空列表与正常修改检查通过。事件原始观察即此记录。
- INC-24，10-06，版本 P24：另一个导入入口把坏 JSON 解析失败当空集合，清空用户设置。机制复现与修正后坏 JSON、合法空列表、正常修改检查均已记录通过；这是独立事件。
- INC-31，10-09，版本 P31：新增同步入口再次触发相同机制，原用户设置被清空。相同输入在修正前复现，修正后用户设置保持，合法空列表正常处理，正常修改生效。
- 10-09 的另一次审查仅再次引用 INC-31，不是新事故。
- ADR-8：默认值只用于内存展示，未知读取结果不能作为写入来源。
