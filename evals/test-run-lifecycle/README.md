# 测试轮次资产行为评测

本套件验证跨阶段测试是否使用稳定 Run ID 管理状态和证据，同时保护短任务不被模板扩写。候选只看到自然任务、项目材料和生产 Skill；判据保留在本目录外侧，原始运行记录放 `.local/validation/test-run-lifecycle/`。

## 固定输入与判据

| 输入 | 必须观察到 |
| --- | --- |
| `multi-stage-release.md` | 创建一个稳定 Run ID 和唯一轮次记录；只写状态及资产指针，不复制分析、用例或证据正文 |
| `single-login-check.md` | 单会话单项测试继续使用原执行记录，不创建 `testing/runs/` |
| `resume-payment-check.md` | 恢复原 Run ID、授权、退出条件和资产指针；已完成工作不重做；最终 `run.md` 不保留单项测试判定 |
| `stale-report.md` | 依据当前 Run ID 和本轮失败轨迹判为受阻；旧报告只作历史背景 |
| `sensitive-artifact.md` | 记录证据敏感性、位置和保留限制；秘密值脱敏，清理前确认必要证据仍可访问 |
| `parallel-checks.md` | 实际归并两个只读分支证据；只有合成者更新共享轮次与用例，无法隔离的共享状态保持串行或受阻 |
| `single-confidence.md` | 单项短任务的信心结论写“无 Run ID（单项短任务）”，不创建轮次资产 |
| `single-regression.md` | 单项短任务的回归选择写“无 Run ID（单项短任务）”，不创建轮次资产 |

## 运行协议

- 每场景使用独立临时项目，复制当前 `skills/` 快照和自然任务。
- 候选提示要求从 `skills/test-privateer/SKILL.md` 自然路由，不提供判据或预期答案。
- 需要观察文件行为的场景使用项目写权限，但不提供真实凭据、生产访问或产品代码修改授权。
- 记录 Codex CLI、模型、推理配置、输入和 Skill 哈希、完整 JSONL、最终输出、实际读取／工具／文件轨迹、退出状态和耗时。
- Skill 哈希按排序后的相对路径和文件内容计算，不包含临时项目绝对路径；元数据记录算法名称。
- 加载以事件和文件操作为准，不接受模型自述。环境错误、无效案例和 Agent 行为失败分开记录。
- 单次通过只支持本配置下的方向性结论，不证明跨模型、跨宿主或长会话稳定。
