# Proposal

## Why

已有技能能调查失败和质检修复，但缺少把真实错误维护为可复用教训、再提炼成项目规则的入口。用户要求参考指定 Magpie 快照与 X 文章，将这套方法内化到本技能包。

## What Changes

- 新增 `maintaining-project-lessons`，覆盖证据整理、同类归并、复发判断、规则晋升与失效维护。
- 区分错题本、长期规则、Agent 入口和原始运行记录的职责；规则与入口可共用 AGENTS.md，保留证据、适用范围和验证动作，避免机械累计和无依据泛化。
- 没有特殊约定时，错题本放项目根目录 LESSONS.md，长期规则直接写入根目录 AGENTS.md；有既有独立规范时继续沿用。
- 主入口增加明确路由，更新安装计数与用户教程；提供可复用行为场景并运行独立上下文检查。
- 根据用户补充约定，实施与验证后保留活动 change，用户明确确认完成后才同步规格并归档。
- 根据用户进一步授权，用新 Skill 初始化本仓库 LESSONS.md，从本次直接记录与有限历史归档提炼协作约束到 AGENTS.md，保留审查范围与证据边界。
- 不引入自动钩子、定时任务、强制文件名或外部服务；不复制 Magpie 的技术、发布和社区规则，不替使用方修改全局配置。

## Capabilities

### New Capabilities

- `project-lessons`: 从真实错误维护项目教训，提炼有范围、有证据、能检查的长期规则。

### Modified Capabilities

- `repository-workflow`: 用户确认本次 change 已完成后才同步当前规格并归档；实施与验证不代替确认。维护本项目真实教训及对应协作规则，修改前读取相关条目。现有调查与质检的职责不变。

## Impact

新增一个发布 Skill 及按需参考和本项目 LESSONS.md；修改主入口、仓库 AGENTS.md 协作规则、README、通用与研发教程、项目说明和 Skill 计数。新增 `evals/project-lessons/` 可复用输入、判据及临时文件维护夹具。无需新增运行依赖。
