# Agent 质量模型

按产品风险选择，不要求每次全部展开。

| 维度 | 关键问题 | 优先证据 |
| --- | --- | --- |
| 任务结果 | 用户目标是否真实完成 | 数据库、文件、API、页面或业务对象状态 |
| 业务规则 | 状态、金额、归属和组合规则是否成立 | 独立计算、契约、可执行检查 |
| 权限安全 | 是否越权、泄露或产生未授权副作用 | runtime policy、审计日志、禁止动作记录 |
| 证据可信 | 完成声明是否来自工具和环境事实 | trace、原始结果、引用与主张映射 |
| 工具行为 | 工具、参数和必要顺序是否正确 | tool call、参数、结果和状态变化 |
| 对话协作 | 是否在正确时机澄清、确认、拒绝或升级人工 | 多轮记录、规则状态、handoff |
| 失败恢复 | 超时、错误、重复和部分成功后是否安全收敛 | 故障注入、恢复状态、停止原因 |
| 稳定性 | 相同条件下是否可靠 | 同场景多次 trial，首试与连续成功 |
| 资源效率 | 延迟、调用、token 和人工介入是否值得 | p50/p95、调用数、成本和接管率 |

```markdown
必要行为：
允许变化：
禁止行为：

```

必要行为只保留任何正确方案都不能省略的部分。若存在多个合理工具或路径，固定结果和不变量，不固定完整轨迹。
