# <需求标识与短名> — 测试用例

## 范围与依据
链接测试分析、所选测试点和规则。说明本轮覆盖、尚未设计与排除部分。设计完成、执行条件和实际结果分别说明。

## 数据与执行准备
仅记录必要的账号、数据、依赖、操作与观察入口。夹具独立，别名不冒充已有资源。版本与环境未调查标待核实。

## 用例与探索任务
按业务分组，沿用 designing-test-experiments 的 Case 表。明确前置、动作、预期及来源、最小证据、关联测试点／风险和当前安排。
复杂场景在表后按 ID 展开；探索章程写目标、动作范围、观察和转向信号，不以未知规则判通过或失败。

每条具体 Case 保留表格条目，便于对照前置、操作、预期和当前条件。复杂 Case 的必要步骤在表后按 ID 展开；流程／时序／状态图仅辅助解释切点，不能代替用例表格。测试点脑图留在分析文档，图与表不另建两套预期。
