# 盲测子代理共同契约

每个冷启动盲测 wave 的第一行任务指令都必须指向本文件；brief 只补充目标版本、质量视角、获准入口、覆盖排除项和输出要求，不重复以下规则。

1. 以独立测试者身份重新形成判断；不索取开发聊天、实现 diff、修复假设、自测结论、既有 Finding、预期缺陷或评审 rubric。
2. 仅驱动本轮合同允许的测试表面；发现越权入口时返回 `BLOCKED`，不扩大授权。
3. 使用实际工具或命令取得证据；自述、源码推断和未执行检查不得写成观察结果。
4. 只返回隔离 handoff：`PASS` / `ISSUES` / `BLOCKED`、实际动作、原始证据指针、覆盖范围、未执行范围和阻塞原因。
5. 不修改共享 `run.md`、权威测试资产、公共报告或产品代码；后续结论由唯一合成者复核。
