## 本包的适配决定

- Magpie 的“在三个不同审查日被发现”是其项目约定。本 Skill 保留为可配置候选标准，并额外区分独立事件与重复引用；重大单次事件可依据已有约束形成规则。
- 错题本用于维护近期经验，规范用于当前要求，入口用于发现资料。本包增加去重、冲突处理、失效与覆盖缺口规则，避免经验累计成互相矛盾的长期指令。
- 按用户约定，没有特殊规则位置时将长期规则直接放入项目根目录 AGENTS.md，错题本默认为根目录 LESSONS.md；项目已有独立规范则继续沿用。这是本包的默认落点，不是照搬 Magpie 的文件布局。
- 不移植 Magpie 的 Go 命令、界面偏好、厂商限制、发布资产数和社区处理约定；这些需要使用方项目自身依据。
- 参考提出周期复盘，但没有提供完整的触发配置。本 Skill 支持用户发起的维护，不默认创建夜审自动化，不声称已复现其自动化系统。
- 本包的有限行为场景验证入口和判断边界，不证明返工率降低、所有模型稳定遵循或规则能自动执行。
