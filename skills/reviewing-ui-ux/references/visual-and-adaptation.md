# 视觉与适配

将视觉现象连接到信息理解、任务操作或有效设计约定。界面更接近某种审美，不自动表示质量更高。

## 设计对照与元素检查

**适用：** 样式偏差、设计还原、元素缺失、布局变化。输入为待评材料、有效设计或组件约定、目标状态及可比的版本；比较与基线处理读取 [证据策略](evidence-strategies.md)。

先定位任务所需元素，分别核对以下主张：

| 主张 | 所需观察 |
| --- | --- |
| 结构中存在 | 结构或控件树中有对应对象；这不保证画面可见 |
| 语义正确 | 角色、名称、值与状态能表达实际用途；需要相应语义证据 |
| 画面可见且可辨认 | 在目标状态和环境下可看见必要文字、图标与状态，未被裁切或遮挡 |
| 可到达、可操作 | 相应输入方式能到达并实施动作，操作轨迹与状态变化可核对 |
| 用户能理解、结果正确 | 用户观察支持理解；实际业务结果支持任务完成 |

按问题检查层级、分组、对齐、间距、密度、字体回退、截断、颜色/图标含义与控件各状态。指出哪项必要信息或操作受影响，再引用设计规则、内容含义或平台约定；没有设计稿时仍可判断明显遮挡，个人偏好则保留为建议。

产出具体位置、状态与差异分类：实现偏离约定、批准的预期变化、体验风险或测量噪声。样式值相同不能证明渲染相同；图像相同也不能证明语义、操作和业务结果正确。数值合规性需按 [无障碍参考](accessibility.md) 核实适用要求。

## 适配与内容边界

**适用：** 界面受空间、内容或使用环境影响。先识别会改变任务的维度，再挑能揭示不同机制的代表组合：

- 空间与显示：窄/宽视口、横竖方向、缩放、文字放大、字体加载/回退、明暗主题。
- 内容与语言：空内容、长标题、极端数量、长译文、双向文本，以及日期、数字、货币和输入习惯。
- 操作环境：键盘、触控、指针、输入法、屏幕键盘与辅助技术；只选目标人群实际相关的条件。
- 任务状态：加载、空态、错误、展开、浮层、滚动位置，以及需要保留的跨页上下文。

在选中组合下检查信息是否保留、阅读顺序是否清楚、主动作是否仍可发现和实施、浮层或键盘是否挡住当前任务。发现问题后固定其他条件，改变内容或空间，缩小触发边界；没有单因素对照时只说问题出现在该组合，不断言唯一原因。

依据产品支持范围、适用标准和任务需求交付所测组合、具体损失及复验边界。抽样不代表穷举，模拟也不等于真实设备与输入；记录未覆盖条件。

**示意——长内容导航：** 宽屏短标签可读，窄屏长译文与“创建”操作重叠。可见证据支持该组合下的信息遮挡；接着固定窄屏改用短标签、固定长文案扩大空间，检查断点附近及另一种文字长度。点击是否受阻需要实际操作，不能从截图直接推断；依据允许的换行或折叠方案判定，不先规定唯一布局。

来源：[W3C 国际化与本地化](https://www.w3.org/International/questions/qa-i18n)、[Web 国际化提示](https://www.w3.org/International/quicktips/)。这些资料提供关注方向，具体产品语言和平台范围仍需明确。
